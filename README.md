# アンケート管理システム
## 作者について
以前にソフトウェア開発の仕事に従事していました。<BR>

## 制作理由
これまでに多くのソフトウェアの開発に従事してきましたが、<BR>
Web系アプリの開発経験がほとんどなかったため、スキルアップのために制作しました。<BR>
アンケート管理システムにした理由はGoogle Formsで作られたアンケートを見て、自分も作ってみようと思ったからです。

## 作品紹介
アンケートの作成、公表、回答の集計等のアンケート全般の管理を行うシステムです。<BR>

- 主な機能
  - アンケートの作成、削除
  - 作成したアンケートの回答
  - アンケートの集計結果の表示
  - ユーザーの登録、更新、削除

- 使用言語およびデータベース
  - 使用言語：Java 17
  - フレームワーク：springboot 4.0.0
  - データベース：MySQL
 
- フォルダ階層
  - [enqueteApp](enqueteApp)：アンケート管理システムのプロジェクトです。
  - [データベース](データベース)：アンケート管理システムで使用するデータベースが入っています。
  - [ドキュメント](ドキュメント)：アンケート管理システムに関する文書が入っています。
