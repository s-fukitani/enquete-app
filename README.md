# アンケート管理システム
## 作者について
以前にソフトウェア開発の仕事に従事していました。<BR>

## 制作理由
これまでに多くのソフトウェアの開発に従事してきましたが、<BR>
Web系アプリの開発経験がほとんどなかったため、スキルアップのために制作しました。<BR>
アンケート管理システムにした理由はGoogle Formsで作られたアンケートを見て、自分も作ってみようと思ったからです。

## こだわった点・苦労した点
  - 複数カメラの制御
    <BR>複数のカメラを操作することで、プレイヤーの主観視点と小マップの俯瞰視点を同時に実装可能にしました。<BR>
    それにより、初心者でも迷うことなくゲームを楽しめるようにしました。
  - エフェクト表現
    <BR>エフェクトアニメーションを入れることで臨場感あふれる戦闘シーンを実現しました。
  - ゲームバランスの調整
    <BR>敵の強さ、経験値、金銭等、快適かつやりごたえがあるようなゲームにするためのバランス調整に苦労しました。
  - 特に苦労した点
    <BR>３Dに不慣れだったため、モデルの作成、カメラの移動および回転等、3D関連のあらゆる面で苦労しました。<BR>
    Webページや参考書を見ながら制作しました。

## 作品紹介
アンケートの作成、公表、回答の集計等のアンケート全般の管理を行うシステムです。<BR>

- 主な機能
  - アンケートの作成、削除
  - 作成したアンケートの回答
  - アンケートの集計結果の表示
  - ユーザーの登録、更新、削除

- 使用言語およびデータベース
  - 使用言語：Java 17
  - フレームワーク：springboot 4.0.0
  - データベース：MySQL
 
- フォルダ階層
  - [enqueteApp](enqueteApp)：アンケート管理システムのプロジェクトです。
  - [データベース](データベース)：アンケート管理システムで使用するデータベースが入っています。
  - [ドキュメント](ドキュメント)：アンケート管理システムに関する文書が入っています。
