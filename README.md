# アンケート管理システム
## 作者について
以前にソフトウェア開発の仕事に従事していました。<BR>

## 制作理由
これまでに多くのソフトウェアの開発に従事してきましたが、<BR>
Web系のアプリの開発経験がほとんどなかったため、スキルアップのために制作しました。

## 作品紹介
アンケートの作成、公表、回答の集計等のアンケート全般の管理を行うシステムです。<BR>

- 主な機能
  - アンケートの作成、削除（管理者のみ使用可能）
  - 作成したアンケートの回答
  - アンケートの集計結果の表示
  - ユーザーの登録、更新、削除（管理者のみ使用可能）

- 使用言語およびデータベース
  - 使用言語：Java 17
  - フレームワーク：springboot 4.0.0
  - データベース：MySQL
