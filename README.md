# アンケート管理システム
## 作者について
以前にソフトウェア開発の仕事に従事していました。<BR>

## 制作理由
これまでに多くのソフトウェアの開発に従事してきましたが、<BR>
Web系アプリの開発経験がほとんどなかったため、スキルアップのために制作しました。<BR>
アンケート管理システムにした理由はGoogle Formsで作られたアンケートを見て、<BR>
おおまかな仕組みを思いつき、自分でも作ってみようと思ったからです。

## こだわった点
アンケート作成においては入力する項目が多いことで、操作が複雑になることと、<BR>
入力ミスが頻発することが想定されたため、確認画面を入れることでミスを発見しやすくし、<BR>
作成をアンケートの骨組みを作る概略と概略に基づいて<BR>
問題と選択肢を入力する詳細に分けることで操作を簡単にしました。<BR>
後、ミスを発見したときに対応しやすくするために一つ前の画面に戻る機能も付けました。

## 苦労した点
アンケート作成においてコントローラからページにアンケートの情報を送る際に<BR>
リストおよびマップを使用する必要があったため、<BR>
受取先のページでデータを受け取るためにnameと<BR>
valueをどの様に記述すれば良いのかなかなか分からずに苦労しました。

## 作品紹介
アンケートの作成、公表、回答の集計等のアンケート全般の管理を行うシステムです。<BR>

- 主な機能
  - アンケートの作成、削除
  - 作成したアンケートの回答
  - アンケートの集計結果の表示
  - ユーザーの登録、更新、削除

- 使用言語およびデータベース
  - 使用言語：Java 17
  - フレームワーク：springboot 4.0.0
  - データベース：MySQL
 
- フォルダ階層
  - [enqueteApp](enqueteApp)：アンケート管理システムのプロジェクトです。
  - [データベース](データベース)：アンケート管理システムで使用するデータベースが入っています。
  - [ドキュメント](ドキュメント)：アンケート管理システムに関する文書が入っています。
